Common questions

FAQ

Does Auto Audio Switcher require Python?

No. The Windows release ZIP includes Python and all required runtime libraries.

Can it switch Windows audio output for a specific program?

Yes. Add a program rule, choose its target output, then select Ask or Auto behavior.

Does it need administrator privileges?

No. The app runs with standard user privileges and stores its writable data in the current user's local app data folder.

Why might Windows SmartScreen show a warning?

The current direct-download executable is not Authenticode-signed. Verify that the download comes from the official GitHub release page and compare the published SHA-256 value.
